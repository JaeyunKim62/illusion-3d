## CUDA run

Install:

```bash
conda env create -f environment.cuda.yml
conda activate illusion-sdf-cuda
npm install
```

Check CUDA:

```bash
python -c "import torch; print(torch.cuda.is_available()); print(torch.version.cuda)"
```

Recommended preview:

```bash
npm run sdf:train:nub-orbit-airplane:preview
npm run sdf:annotate
npm run sdf:evaluate
npm run sdf:qa
```

Recommended full:

```bash
npm run sdf:train:nub-orbit-airplane
npm run sdf:annotate
npm run sdf:evaluate
npm run sdf:qa
```

All-generated companion preview:

```bash
npm run sdf:train:nub-cathedral-fountain:preview
npm run sdf:annotate
npm run sdf:evaluate
npm run sdf:qa
```

All-generated companion full:

```bash
npm run sdf:train:nub-cathedral-fountain
npm run sdf:annotate
npm run sdf:evaluate
npm run sdf:qa
```

Open the viewer:

```bash
npm run sdf:serve
```

Then visit:

```text
http://127.0.0.1:8000/index.html
http://127.0.0.1:8000/record.html
http://127.0.0.1:8000/candidate_previews/nub-orbit-airplane.png
http://127.0.0.1:8000/candidate_previews/nub-cathedral-fountain.png
```

## Notes

- `points.json` and `learned_sdfs.pt` are overwritten by training.
- `points-sdf.json` is regenerated by `npm run sdf:annotate`.
- `projection-metrics.json` is regenerated by `npm run sdf:evaluate`.
- Use `F` in the viewer for SDF field reveal.
- Use `I`, `1`, `2`, `3` for reference-image diagnostics.
